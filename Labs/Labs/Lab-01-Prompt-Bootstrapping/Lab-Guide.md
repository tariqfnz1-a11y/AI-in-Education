## 👋 Welcome

Have you ever asked AI to:

- Create a lesson plan
- Make a quiz
- Write report card comments
- Prepare a parent message

...only to spend more time editing the answer than it would have taken to write it yourself?

You're not alone.

The problem usually isn't the AI.

It's the prompt.

In this lab, you'll learn one simple technique that professional AI users rely on every day:

> **Prompt Bootstrapping**

Instead of asking AI to complete a task immediately, you'll first ask AI to improve your prompt.

That one extra step can dramatically improve the quality of the final response.

---

# 🎯 Learning Outcomes

By the end of this lab, you will be able to:

- ✅ Explain Prompt Bootstrapping.
- ✅ Improve weak AI prompts.
- ✅ Create classroom-ready prompts.
- ✅ Save your first reusable prompt.
