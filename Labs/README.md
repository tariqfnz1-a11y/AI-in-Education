# 📘 AI Teaching Lab #01

# Prompt Bootstrapping

> Learn how to let AI improve your prompts before asking AI to complete your task.

---

## 👋 Welcome

Have you ever asked AI to create a lesson plan, worksheet, quiz, or parent message and then spent more time editing the answer than writing it yourself?

The problem is often **not the AI**—it's the prompt.

This lab introduces **Prompt Bootstrapping**, a simple technique that helps AI rewrite your prompt before generating the final answer.

---

## 🎯 What You'll Learn

By the end of this lab, you will be able to:

- Improve weak AI prompts
- Create clearer and more detailed prompts
- Generate better classroom resources
- Build your first reusable prompt
